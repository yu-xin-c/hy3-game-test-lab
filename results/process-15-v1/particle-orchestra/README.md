# 粒子音轨：通关分数多加了 100

题面规定 A、C、D、B 四次正确输入各得 25 分，完成后总分 100。原编号方案第 3 步却写“每次 +25，通关再 +100”；最终代码照做，三次 Chromium win-path 的终点均为 `score=200`。独立[得分核验](SCORE-PLAN-CLAIM.md)按公开规则直接算出 100，混元也把首次错误方案步骤定位到第 3 步并归为题意误读。

原检查还在终局要求 `active_cluster=B`；题面只要求观察状态包含这个字段，未规定终局必须保持最后高亮。混元将该项列为证据不足，不能把它与 100 分差值混在一起。得分错误是真实生成错误，额外的终局高亮检查是标准风险。
