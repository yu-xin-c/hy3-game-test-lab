# Mini Farm：启动后按钮更新晚一帧

冻结通关路径在 Start 后立即选第一块田，原浏览器记录的 Plot/Plant/Water 按钮当时仍 disabled，输入超时；失败路径只等待 15 秒，能够正确判负。原结果不覆盖。

[追加 Chromium 对照](start-timing-probe.json)使用同一生成游戏与已保存哈希，冻结时钟后由真实鼠标点击 Start：状态和事件立即进入 Playing，但 Plot/Plant 仍不可点 **3/3**；推进 32ms 后按钮可点 **3/3**。按公开规则种植、浇水、等待 3032ms、收获三田，真实路径 **3/3** 获胜并得到 30 金币。

代码中 `start()` 改状态、记事件和存档，却不立即调用 `updateUI()`；按钮只能在下一次 animation frame 中启用。原方案第 1 步的“直接依次点击”验证主张因此在冻结时钟下不成立；游戏核心路径有等待一帧的办法走通。这里先记录独立可复现的首个**已知**方案断言问题，等待原始混元复核后再比较其定位。不能把原固定路径输入超时当成整个游戏不可玩。
