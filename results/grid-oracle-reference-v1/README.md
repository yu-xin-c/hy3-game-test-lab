# 钥匙迷宫：独立网格判据核验

从生成时保存的公开题面解析 8×5 地图，按墙、锁门、钥匙、陷阱、出口和重开规则计算固定输入路径。不读取生成的 game.js，也不使用 Hy3 的判据核对意见来生成期望状态。

三条路径共 38 个状态断言：36 个与独立计算一致，2 个不作确定判断，没有确定性不匹配。这里不是游戏通过率，也不认证 UI、事件或输入合同。

两个未确定项在生命归零的检查点：has_key=true、door_open=false。参考模型保守地不规定“立即失败”和“恢复本条生命初始状态”的执行先后，不把其中一种实现顺序当成公开要求。原始检查和成绩没有改写。

这同时核验了模型提出的一条坐标疑问：A33 实际要求 player.y=1，并非模型解释中的 y=3。锁门、开门、出口都在 y=1；第一次踩陷阱后回起点 (1,1)，重开也回起点。对应检查值均与参考路径一致，因此不采纳这条模型质疑。

result.json 保存地图、每步参考状态、全部检查项比较及输入/参考程序哈希。参考模型只覆盖这款题目的状态规则，其正确性仍以公开规则和单元测试为依据，不声称形式化证明了完整游戏。
