# 完整游戏任务集

这里有 96 个浏览器游戏任务。最初参考 106 条跑批的汇总分布构造，现已移除 10 道摄像头题，不增加替代题。原始 query 不在本机，这些题是按分布重新编写，并非逐条抽样。

| 玩法 | 数量 |
|---|---:|
| 动作 / 反应 / 竞技 | 31 |
| 益智 / 棋盘 / 解谜 | 26 |
| 创意 / 展示 / 交互 | 13 |
| 养成 / 模拟 / 经营 | 16 |
| 教育 / 叙事 / 剧情 | 10 |

可叠加特征：3D 13 题、多人 15 题、存档 13 题、排行榜 10 题、触控 6 题；无摄像头题。移除后不再声称与原分布完全一致。旧题在 [归档目录](../archived-camera-tasks/README.md)，不参与当前生成与汇总。

每个任务目录固定包含四个文件：

- `brief.md`：交给混元的完整游戏要求。
- `test-plan.json`：通关、失败、重开的真实操作路径。
- `oracle.private.json`：每个检查点的正确状态、事件和界面结果。
- `input-sha256.txt`：上述输入和公共生成要求的哈希。

生成时，模型只能看到 `brief.md` 和上级目录的 `GAME_CONTRACT.md`。游戏文件冻结后，评测器才读取测试路径和正确结果。

```bash
pnpm run build:game-tasks
pnpm run check:game-tasks
```

当前难度分布为 D1 12 题、D2 57 题、D3 27 题。五个早期任务保留了更长的定制路径；其余任务使用各自玩法的三段主路径，并同样包含失败和重开测试。
