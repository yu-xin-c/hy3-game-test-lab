# Demo 媒体

正式提交在本目录放置一个不超过 120 秒的演示视频或 GIF。当前 README 只是交付约定，不代表媒体文件已经生成。

推荐文件名：

```text
prd2play-demo.mp4
# 或
prd2play-demo.gif
```

发布时在下表填写真实信息：

| 字段 | 值 |
| --- | --- |
| 文件 | 待生成 |
| 时长 | 待生成（必须 ≤120 秒） |
| 分辨率/编码 | 待生成 |
| 对应 Git commit | 待生成 |
| 对应 run ID | 待生成 |
| SHA-256 | 待生成 |
| 字幕/旁白语言 | 中文（计划） |

录制分镜见 `docs/demo-script.md`。成片必须展示真实浏览器输入、逐步首错、终局/过程差异和脱敏结果；不得显示 `.env`、API key、私有端点或未授权素材。
