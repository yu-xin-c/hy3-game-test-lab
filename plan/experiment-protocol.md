# 当前实验方案

发布数据为96题，不含摄像头、视频和语音输入。公开要求与私有检查隔离，生成和模型复核均为Hy3，真实Chromium重放保存状态、事件、HUD和输入哈希。

已完成：96题运行评测；3题编号公开方案与真实写入过程；真实游戏错误复验与局部干预；两条公开要求、四个代码版本的自动评估器验证。各批次分开统计，不将规则通过率当作独立模型准确率。

自动评估器实验的冻结标准、对照、指标、效率与稳健性边界见 [专项协议](../experiments/verifier-v1/plan/experiment-protocol.md)。原始/修正对照用于验证评估器，不计作新生成样本。

原先设想的106题、摄像头和重复生成扩展不属于本次实际结果；不以规划代替执行证据。
