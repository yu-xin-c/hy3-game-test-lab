# 公开方案断言核验

对象：原始 Hy3 Signal Memory 方案的 verification 字段。固定两个前缀：步骤 1，步骤 1–2；不改写原文、不生成伪造方案。是同一游戏的相关诊断对照，不是两款独立游戏，也不估计泛化准确率。

独立判据：步骤 1 的五个 DOM 元素存在，Canvas width/height 为 800/600；步骤 2 声称 reset(seed=1) 后 sequence=[RED,BLUE]、progress=0，相同 seed 再重置结果相同。真实 Chromium 执行这些检查，每个新上下文两次重置，共三个上下文。不同 seed 的断言和其他字段不在此次范围。

评估器：Hy3，输入原方案前缀及真实观测，判断所选 verification 断言是否成立，并返回首次被证据反驳的步骤。不提供规则结论或标签。判据和协议先写，再运行浏览器、再请求模型；这是事后挑选的诊断样本，不称盲选测试集。

计分：每个前缀计一次，重复运行不扩大分母；错误前缀需判断存在问题且 first_error_step 与独立判据一致。正常前缀统计误报。无法判断单列，不能当作正确。仅报告原始计数，不做区间或难度外推。

主对照为同一原始计划的一步前缀和两步前缀。没有其他模型基线；不声称优于其他评估器。效率保存调用 usage，不做速度优势比较。无模块收益声明，因此不做消融。重置重复为执行稳健性检查，不代表跨游戏泛化。解释性仅核对定位到原文步骤，不评价内部思维过程。
