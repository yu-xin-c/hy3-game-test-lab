# 前缀证据隔离对照

复用 v2-final 的两个游戏、四个前缀、12 次真实浏览器运行。观测和 gold 字节不变，先核验原冻结哈希。没有新游戏、没有新的独立样本，也不改首错标签。本次是在看到 v2 越界解释后设计的诊断对照，不是盲测泛化集。

唯一改变为单步前缀的模型输入：Target 只保留 Start 后 status 和事件；Platform 只保留输入时间表及每个观测点 player.x/y/vx/vy、latest_event_seq，用于判断重放一致性。单步范围说明不含步骤 2，原文步骤保持不变。两步前缀不改。四份评审均在独立调用目录重新请求 Hy3，提示模板与 v2 相同。

在调用前冻结观测、标准、输入包及版本元数据。与 v2 逐前缀比较结构化判断、首错和未知数；正常前缀的未知不当作通过。四个前缀相关，错误样本只有一个，报告原始计数，不作显著性或总体误报外推。保留原输出，不替换 v2 的得分。

这是输入范围的单项对照，没有其他模块消融，也不主张优于其他模型。复用同一观察控制游戏和执行差异，模型随机性未通过多轮模型重复排除。效率保留调用 usage，不比较速度优势。解释只检查是否讨论不在 steps 中的步骤；不认证内部推理或整份方案。
